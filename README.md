# 在线计时器 · Online Timer

一个纯前端的单页计时工具，打开网页就能用，无需安装、无需注册，数据不经过任何服务器。

## 在线访问

👉 **GitHub Pages：** https://ruige7.github.io/online-timer/

（本地使用：直接双击 `index.html` 在浏览器打开也可以。）

## 功能

### ⏱ 秒表
- 开始 / 暂停 / 重置
- 计次（Lap）：记录每圈用时与累计用时，最新一次置顶显示
- 精度到百分之一秒

### ⏳ 倒计时
- 自由设置 时 / 分 / 秒
- 结束时屏幕闪烁提示 + Web Audio 蜂鸣声（共 3 声）
- 支持暂停后继续、随时重置

### 🍅 番茄钟
- 一键切换预设：**专注 25 分钟** / **休息 5 分钟**
- 专注结束自动累计已完成番茄数
- 结束同样有闪烁 + 蜂鸣提醒

## 技术说明

- 单文件实现：`index.html` 内包含全部 CSS 与 JavaScript，零依赖、零构建
- 深色简洁界面，适配手机与电脑
- 计时基于系统时间戳计算，切换标签页也不会漂移
- 蜂鸣使用 Web Audio API 现场合成，无需任何音频文件

## 使用提示

- 浏览器要求用户先有一次点击才会播放声音，所以点「开始」时会自动初始化音频，这是正常现象。
- 计时进行中请不要关闭页面；刷新页面会重置当前计时。
